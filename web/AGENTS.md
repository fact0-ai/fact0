# Fact0 web

This release is a single-owner self-hosted experiment. No cloud identity, billing, email, analytics or LLM service is required. Keep browser requests same-origin and backend service URLs server-only. Do not restore default authentication secrets or public signup.

Before changing Next.js code, read the relevant installed guide in node_modules/next/dist/docs/. This is Next.js 16 with proxy.ts and asynchronous route parameters.

Preserve raw captured payloads, label incomplete capture, and distinguish replaying stored events from rerunning the agent.
