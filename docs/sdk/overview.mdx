title: "Client SDKs"
description: "Existing client packages with an explicit self-hosted destination."
---

The repository includes Python (`fact0-sdk`, imported as `fact0`), TypeScript (`@fact0/sdk`) and Go (`github.com/fact0-ai/fact0/sdk/go`) clients.

Create an API key in your local dashboard. Set your own API URL explicitly using Python `base_url`, TypeScript `baseUrl` or Go `BaseURL`. Published defaults retain their existing behavior and must not be relied on to select your local installation.

Start with the [tested Python walkthrough](/sdk/python/installation). Existing framework integration pages are recipes; they do not extend the supported core to hosted services, OTLP or policy enforcement. Keep secrets out of source and call flush/close for buffered clients.
