---
title: "Core release notes"
description: "Experimental self-hosted core v0.1.0."
---

The first core release brings the Go API and Next.js application into the existing SDK/plugin repository as a reviewed source snapshot, without importing private application history.

It adds a single-owner Docker Compose installation, password provisioning, tracked fresh-database setup, persistent export signing, focused Python/Claude workflows, and a self-hosted documentation path.

The supported surface excludes SaaS billing, invitations, administration, Spotlight, external alerts/sharing, policy enforcement and OTLP. Automatic record expiration is disabled. See the root release notes for validation evidence and remaining limitations.

Fresh installations are supported. This release is not a migration path for existing hosted databases.
