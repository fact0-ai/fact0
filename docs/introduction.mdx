---
title: "Fact0"
description: "Self-hosted execution inspection and audit records for AI agents."
---

Fact0 helps you inspect recorded agent executions and maintain a separate hash-chained audit log. Run the Go API, Next.js dashboard and PostgreSQL on your own machine or server.

Start with [installation](/quickstart), then choose the deterministic [Python example](/sdk/python/installation) or [Claude Code integration](/integrations/claude-code). Neither the core installation nor the Python example needs a model account. Claude Code uses your existing Claude configuration.

The release is experimental, MIT licensed and maintained on a best-effort basis. It supports one owner and one workspace, with password login and API keys. There is no SLA or compliance certification.

Replay reconstructs recorded history. A valid audit chain checks consistency of stored records; it cannot establish that every action was captured or that a database administrator is trustworthy. Read the [verification limits](/guides/verification).
