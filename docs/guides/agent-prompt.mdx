---
title: "Instructions for an integration agent"
description: "A local-first integration brief."
---

Give an integration agent the following brief, together with your application code. Supply the API key through the environment rather than placing it in the prompt.

```text
Integrate the Fact0 SDK with this application. Use the existing Fact0 checkout's
SDK and examples/local-python.py as the contract. Read FACT0_API_KEY and
FACT0_BASE_URL from the environment and pass the base URL explicitly.
Record executions, nested spans and relevant audit outcomes. Ensure parent
spans are created before child spans and clients flush/close before exit.
Inspect recorded results and verification status to detect failed delivery.
Never send credentials or private application data to the hosted default URL.
Do not enable billing, sharing, governance or OTLP for this core release.
```

Start with [Python installation](/sdk/python/installation) or [Claude Code](/integrations/claude-code).
